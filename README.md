# GrammarFix: AI Proofreader

GrammarFix is a menu bar app that fixes the grammar of whatever text you have selected, in any app: right-click it and choose Services › GrammarFix: Fix Text, or use a keyboard shortcut.

- **Get it:** [GrammarFix on the Mac App Store](https://apps.apple.com/app/apple-store/id6818731444?pt=118810532&mt=8&ct=github-support)
- **Website:** [grammarfixai.app](https://grammarfixai.app/)
- [Privacy policy](PRIVACY.md)
- **Support:** email [support@grammarfixai.app](mailto:support@grammarfixai.app), or open an [issue](https://github.com/aleibovici/grammarfix-support/issues) for questions, bug reports and feature requests. Please include your macOS version, the provider and model you used, the app you were typing in, and the error shown in the GrammarFix menu, if any. Never include your API key.
