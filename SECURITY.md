# GrammarFix Security Policy

## Reporting a problem

If you find a security problem in GrammarFix, email support@grammarfixai.app with "Security" in the subject. Please don't open a public GitHub issue for it.

Include the GrammarFix version (shown in GrammarFix Settings), your macOS version, the provider you use, and the steps to reproduce it. Never include your API key.

You'll get a reply within 3 working days. Please give the developer a reasonable time to fix the problem before you talk about it publicly.

## Supported versions

Fixes go into the latest version on the Mac App Store. Updating to it is the way to get them.

## Fixed problems

When a security problem is fixed, the App Store release notes and this page say so, with what was affected and what to do.
